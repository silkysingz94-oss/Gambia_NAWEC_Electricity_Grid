Methodology and data limitations

Features are queried live from OpenStreetMap using the Overpass API. The map displays objects tagged as power plants, generators, substations, transformers, power lines, minor lines, cables, towers and poles within the Gambia query area.

Line length is calculated from the mapped geometry. Capacity is summed only where a capacity tag can be interpreted as MW. Untagged or incomplete infrastructure is not estimated.

This is an open-data screening and visualisation tool, not a live SCADA system, asset-condition survey, outage map, or official NAWEC engineering database. A missing feature does not mean the infrastructure does not exist.
